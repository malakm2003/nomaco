# The Noma Photobooth — thenomaco.com

*Pics or it didn't happen!*

One-page site for The Noma Photobooth, a receipt-style photo booth for events, cafés and small businesses.

**Domain:** thenomaco.com
**Hosting:** Netlify (connected to this GitHub repo)
**Bookings:** Formspree form `xbdejkyr`
**Instagram:** [@thenomaco](https://instagram.com/thenomaco)

## Preview locally

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080. No build step.

## Files

```
index.html            ← the whole page
css/style.css         ← brand colours, fonts, layout
js/main.js            ← receipt animation, scroll reveals, Formspree form
images/noma-logo.png  ← logo wordmark (transparent, recoloured in CSS)
images/               ← app icons + original logo
favicon-32.png        ← browser tab icon
```
